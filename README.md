# PeerLearn Connect

PeerLearn Connect is a front-end prototype for a peer-to-peer skill exchange platform. Students can explore skills, list skills they can teach, review learning requests, and track exchanges.

## Features
- Responsive dashboard
- Browse skill listings
- Add and manage skills (demo UI)
- Learning requests and exchange progress screens
- Profile overview

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

This is a client-side prototype. Authentication, database persistence, and real messaging are not connected yet; the sample records are demonstration data.
